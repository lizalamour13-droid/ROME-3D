# Prière d'ambiance

`priere.mp3` est une récitation française synthétique du Notre Père, dont le texte figure dans `priere.txt`. Aucun enregistrement de personne réelle n'est utilisé. Le fichier est généré hors ligne avec eSpeak NG 1.52 (voix `fr-fr`, vitesse 118, hauteur 31), puis traité avec FFmpeg : doublage discret décalé, réverbération légère, normalisation et silence entre les répétitions. Durée : environ 33 secondes. Ces outils ne sont pas nécessaires pour jouer : le MP3 est livré avec le site.

La lecture démarre seulement après une action de l'utilisateur, se règle en volume et se met en pause à la sortie de la seconde salle. Aucun microphone ou service vocal externe n'est utilisé.
